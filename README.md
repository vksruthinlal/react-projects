# React Projects

This repository contains React applications developed as part of my Git & GitHub Final Machine Test.

## Projects

### 1. Authentication Application
- React and Vite
- Email and password form
- Form validation using required fields
- Responsive login interface
- Frontend demonstration only; backend authentication is not implemented

### 2. Task Management Application
- React and Vite
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Display total and completed task counts
- Responsive layout

## Technologies Used
- React
- JavaScript
- HTML5
- CSS3
- Vite
- ESLint

## How to Run

Open the required project folder in the terminal and run:

```bash
npm install
npm run dev
```

Open the local URL displayed in the terminal.
